# Asterra: The Equal Dawn

A persistent, solo, improvisational fantasy story game. The player is the only hero; the Game Master (Arena) runs the world, NPCs, magic, consequences, and continuity.

## Game files

- [`WORLD_BIBLE.md`](WORLD_BIBLE.md) — world, laws, magic, factions, and the D100 rules.
- [`GAME_STATE.md`](GAME_STATE.md) — the current canonical state of the adventure.
- [`GAME_LOG.md`](GAME_LOG.md) — the turn-by-turn chronicle.
- [`assets/`](assets/) — one illustrated scene for every movement/turn.

## How to play

Declare an action, dialogue, question, or plan in the decision prompt. The Game Master rolls a transparent D100 after the intent is clear, applies circumstances, narrates the result, updates the state, and creates the next scene image. There is no fixed class or single correct path: the character becomes what their choices make them.
